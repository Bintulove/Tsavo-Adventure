# EduSavvy — Tsavo 4D Fluency Challenge

## Overview
This repository contains redesigned AI interactions for EduSavvy, a Nairobi-based edtech startup building AI-powered learning support for secondary school students across East Africa.

The project applies the **4D Framework**:
- Delegation
- Description
- Discernment
- Diligence

## Goals
- Improve local relevance
- Reduce hallucinations
- Support low-bandwidth learners
- Align with CBC & PLE curriculum systems
